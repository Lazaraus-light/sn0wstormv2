# Sn0wStormV2

Sn0wStormV2 is a helper bot for Discord servers. It welcomes new people, keeps spam away, gives members a private way to reach the moderators, and helps the moderators keep track of what's happened. It can also record D&D sessions for groups who agree to it.

## Guides

- [For members](User_manuals/User_functions.md): what the bot does and the commands everyone can use
- [For moderators and admins](User_manuals/Admin_functions.md): moderating, setting up a server and saving server themes
- [For D&D players and DMs](User_manuals/DnD_functions.md): campaigns and session recording
- [Example server rules](SERVER_RULES.md): a ready-made set of rules that fits the bot

## Report a problem or suggest something

Found something that doesn't work, or have an idea? [Open an issue](https://github.com/Lazaraus-light/sn0wstormv2/issues/new/choose). You'll need a free GitHub account.

**Issues are public.** Anyone can read them, so please don't include personal information, private messages or anything about another member.

- **A problem with a moderator's decision:** talk to that server's moderators.
- **A question, or a request about your data:** message **gramzon** on Discord.
- **A security problem:** use the [private security form](https://github.com/Lazaraus-light/sn0wstormv2/security/advisories/new). Please don't post it as an issue.
